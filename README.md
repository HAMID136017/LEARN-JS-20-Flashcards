# مرکز فلش‌کارت‌های مسیر یادگیری حمید

[ورود به فلش‌کارت‌های تعاملی](https://hamid136017.github.io/LEARN-JS-20-Flashcards/)

این پروژه از یک مجموعهٔ تک‌درسی به مرکز فلش‌کارت‌های چنددرسی تبدیل شده است. هر کارت شامل سؤال، پاسخ کوتاه، طرح‌وارهٔ فهم و دلیل یا کاربرد است.

## درس‌ها

- **JavaScript امنیتی — ۲۰ کارت:** مبانی، شرط و تابع، داده و شیء، DOM، درخواست و پاسخ API و نکته‌های امنیتی.
- **SQL — ۳۷ کارت:** Query و MySQL، SELECT و WHERE، شرط‌ها، IN، BETWEEN، NULL، مرتب‌سازی، COUNT، DISTINCT، MIN و MAX، GROUP BY، HAVING، AS، AVG و SUM.
- **Linux/Bash — ۵۳ کارت:** مسیرها، فایل‌ها، مجوزها، grep، شرط‌ها، آرگومان‌ها، حلقه‌ها، کدهای خروج، گزارش و جست‌وجوی بازگشتی.

## امکانات

- منوی جدا برای هر درس
- فیلتر براساس سرفصل
- برگرداندن کارت برای دیدن پاسخ
- طرح‌وارهٔ مرحله‌ای پشت هر کارت
- ذخیرهٔ جداگانهٔ پیشرفت هر درس در مرورگر
- فیلتر «مرور دوباره» برای کارت‌های یادگرفته‌نشده
- آمیختن کارت‌ها و کنترل با صفحه‌کلید

## روش مرور

1. ابتدا بدون دیدن پاسخ، جواب بده.
2. کارت را برگردان و پاسخ را با طرح‌واره مقایسه کن.
3. اگر پاسخ را فهمیدی، دکمهٔ «یاد گرفتم» را بزن.
4. از فیلتر «مرور دوباره» برای تکرار موارد باقی‌مانده استفاده کن.

روش ساخت کارت‌ها بر پایهٔ **MAKE FLASHCARDS** است و پاسخ‌ها با طرح‌وارهٔ کوتاه برای مرور سریع ارائه می‌شوند.
